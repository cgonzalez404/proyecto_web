# StockMarket Pro

Proyecto monorepo para una plataforma profesional de compra y venta de acciones.

## Arquitectura

- `frontend/`: aplicación web con React 19, Vite, React Router, Bootstrap 5, Axios, Chart.js.
- `backend/`: API REST con Node.js y Express para autenticación, usuarios, cartera y operaciones.
- `database/`: scripts SQL, esquema de PostgreSQL y guía de migración.

## Preparación para despliegue

- Frontend preparado para Vercel
- Backend preparado para Render
- Control de versiones con Git/GitHub

## Fases de desarrollo

1. Estructura base y dependencias
2. Diseño y layout de la interfaz
3. Integración con autenticación JWT
4. Conexión con Alpha Vantage
5. Operaciones de compra/venta y visualización de gráficos
6. Despliegue y documentación final
